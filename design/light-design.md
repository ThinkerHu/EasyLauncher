# 云山桌面 · 原生量产规格基线

选定方向：第三轮方案 01「云山」。应用包名 `com.vincenthu.launcher`，原生开发版本 `0.2.0`。文件名沿用早期轻彩文档路径，内容以云山为准。

## 视觉

山景蓝灰渐变作为默认背景，远山和暖色日轮提供低对比层次。顶部使用白色日期与问候语；天气卡为浅蓝灰表面，日历卡为米白表面，底部常驻栏使用半透明浅色表面。应用保留真实图标和系统名称，文字采用高对比蓝灰色。

## 自适应布局

| 区域 | 横屏 | 竖屏 |
| --- | --- | --- |
| 顶部操作 | 产品名、整理、设置 | 保持相同入口 |
| 信息区 | 日期 / 问候在左，天气与日历并排在右 | 日期 / 问候在上，天气与日历并排在下 |
| 应用网格 | 7 列 × 2 行，每页 14 个入口 | 4 列 × 4 行，每页 14 个入口 |
| 系统小组件 | 可选卡片，位于应用分页前 | 可选卡片，位于应用分页前 |
| 页码 | 左箭头、当前页 / 总页数、右箭头 | 同样保持可见 |
| 常驻栏 | 应用库 + 最多 4 个应用 | 顺序相同，随宽度缩放 |

应用网格使用可用高度自适应图标尺寸，最低保留 32dp。桌面、弹窗和系统小组件均使用安全区域；输入法出现时，弹窗采用 `adjustResize`，不遮挡搜索框和关闭按钮。

## 交互

1. 点按图标启动真实应用；左右滑动或点击箭头翻页。收到 HOME Intent 时关闭浮层并回到第一页。
2. 点击常驻栏九宫格打开全部应用。按名称或包名筛选，点图标启动，长按添加到桌面或常驻栏。
3. 长按应用或点击“整理”进入编辑模式。拖动应用可直接换位；整理菜单支持移到第一页、前后移动、移除入口、常驻栏开关和应用信息。移除入口不会卸载应用。
4. “整理 → 新建文件夹”输入名称并选择至少两个应用。文件夹可打开、重命名、解散；解散后恢复独立入口。
5. 点击天气卡打开城市选择和刷新；联网失败时优先显示缓存。点击日历卡首次请求系统日历权限，授权后读取当天事件，没有事件时显示空状态并可打开系统日历。
6. “设置 → 添加系统小组件”列出设备公开的 AppWidgetProvider。选择 provider 后由系统确认绑定，必要时进入 provider 配置 Activity；绑定完成后持久化 widgetId，编辑模式可移除。
7. “设置 → 设为默认桌面”使用 RoleManager 或系统 HOME 设置页，由用户确认默认桌面，不在应用内静默替换。

## 数据状态

- 日期：设备系统时间，每 15 秒更新显示。
- 天气：Open-Meteo 当前温度、天气描述和当日高低温；城市选择保存到本机。成功结果写入缓存，断网或服务错误时回退缓存；没有缓存时显示安全错误状态。
- 日历：`CalendarContract.Instances` 查询当天实例，处理时区、全天事件和重复事件，最多展示 5 项；仅申请 `READ_CALENDAR`，拒绝不影响其他桌面功能。
- 系统小组件：由 `AppWidgetManager` / `AppWidgetHost` 管理，绑定和配置走系统 Activity；provider 被卸载或不可用时显示可移除的“不可用”卡片。

## 量产验收要求

开发验证已覆盖荣耀 BAH3-W59 的联网天气、断网缓存、日历授权拒绝 / 允许、widget 绑定确认、进程重启、横竖屏和移除。正式发布前还需完成 release 签名、R8、网络与隐私审查、多型号设备矩阵、字体缩放、多窗口、长时间运行和崩溃回收验证。
