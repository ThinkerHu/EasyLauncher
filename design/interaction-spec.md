# EasyLauncher · VOL.02 交互规范

产品：EasyLauncher。包名：`com.vincenthu.launcher`。版本：0.2.0。

## 设计基准

完全重新选择信息架构，十个方向分别以栏目、磁贴、意图、时间、任务、空间、命令、文字索引、场景、渐进浏览为核心。各方案不共用图标网格或 Dock 骨架。

目标设备屏幕为 1920×3000 px、400 dpi，设计空间为横屏 1200×768、竖屏 768×1200。H5 等比呈现设计空间；原生阶段还需按窗口 Insets 处理系统栏、键盘和多窗口。

## 旋转与状态

- 当前方案由稳定 ID 标识，各方案有独立的演示状态。
- 旋转只修改 `data-direction`、屏幕尺寸和缩放，不重绘交互 DOM；因此输入、焦点、应用浮层与任务状态保持。
- 杂志跨页改为竖向阅读；磁贴四列改两列；罗盘面板由右移到下方；时间轴由水平改垂直。
- 看板三列改三条分组；地图按方向重定位节点；命令台帮助由右移到下方；文字索引标题移至顶部。
- 场景舞台由并列改上下；卡片栈由右侧移到文案下方。节点 ID、书签、场景与卡片页码不变。
- 看板分组和文字索引允许独立滚动，底部应用库 / 返回入口固定可用。

## 交互与反馈

- 普通点击反馈约 180ms；浮层背景约 180ms 淡入，内容约 250ms 进入。
- 卡片栈水平滑动超过 45 屏幕像素、且横向位移超过纵向 1.4 倍时翻卡；按钮区域不触发滑动。
- 磁贴提供明确「调整布局 / 完成调整」模式；置顶按稳定 ID 修改顺序。
- 看板按任务 ID 移动阶段；新增输入限制 30 字，空白内容不能提交；最多 8 件任务。
- 地图是桌面应用群的示意空间，不是地理地图或定位服务。
- 命令台对应用中文名与英文 ID 做本地过滤，Enter 执行首项；内置命令仅影响原型界面。
- 保留可见焦点，浮层提供语义 dialog、关闭、Tab 循环和 Esc 返回；减少动态效果时关闭非必要动画。

## 选择流程

候选允许多选。最终选择只保留一个，但可随时更换。候选和最终结果保存在浏览器，不自动发送给任何第三方。JSON 导出包含项目名、applicationId、版本、候选方案 ID / 名称 / 旋转说明、最终方案和导出时间。

## 实现范围

这是交互选型，未安装 Android APK。普通 Launcher 可以实现这些桌面自身的 UI 与应用启动；真实日程、内容预览、智能分组、跨应用数据接续需要后续评估公开 API 与用户授权。原生实施先完成 HOME 注册、真实应用列表、启动与返回、旋转与状态持久化，再处理真实数据接入。
