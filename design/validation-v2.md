# EasyLauncher · VOL.02 验证记录

验证日期：2026-11-11（Asia/Shanghai）。版本：0.2.0。环境：桌面应用内浏览器，本地 HTTP 服务。

## 布局与方向

- 检查全部 10 个方案的横屏与竖屏初始布局，共 20 个画面，保存逐张截图并生成两张总览。
- 横屏设计空间为 1200×768，竖屏为 768×1200；检查页面无横向溢出，主要操作与底部桌面导航可见。
- 检查 320×740、390×844、820×1180、1920×1200 浏览器视口，页面无横向溢出。测试完成后还原视口。
- 任务板横屏分组高度调整为 470，竖屏维持 855；再次检查两种方向的任务统计与导航不重叠。长分组内部滚动。
- 完整文字索引有 18 行，列表区域可独立滚动。

## 通用流程

- 全屏进入和退出均可操作。
- 应用库搜索 wechat，旋转后输入保留且仅显示微信。
- 候选加入后，候选筛选只显示对应行；移出后恢复。候选在页面刷新后保持。
- 下载并读取 `EasyLauncher-v2-selection.json`，确认项目名、`com.vincenthu.launcher`、版本、候选 ID / 名称 / 旋转描述与空的最终选择正确。
- 测试后移出测试候选，未替用户预选最终方案。
- 工作流检查后浏览器错误日志为空。
- `npm run check` 通过，覆盖当前原型与第一轮存档 JavaScript 的语法。

## 范围与限制

本轮为 H5 交互选型，未在荣耀真机上执行安装或系统 Launcher 验证。应用打开、时间、天气、内容与任务均为本地演示。

卡片翻页的可见按钮已操作验证；真实触摸滑动、系统软键盘、MagicOS 旋转行为、多窗口和系统栏需要在后续 Android 真机阶段验证。最终单选写入路径已实现，本次未保存任何最终选择。
