# EasyLauncher 交互设计规范 · v0.1

产品名：EasyLauncher。Android 包名：`com.vincenthu.launcher`。

## 目标与测量基准

当前交付用于选择设计方向，不是可安装的桌面 APK。

设备实测分辨率为竖屏 1920 × 3000 px，逻辑密度 400 dpi。以 2.5 px/dp 折算，设计基准为横屏 1200 × 768 dp / 竖屏 768 × 1200 dp。H5 中的 dp 标签表示设计空间；浏览器通过等比缩放呈现这个空间。真实 Android 布局还需从可用窗口尺寸中扣除系统 Insets。

五个设计共用应用标识和图标语义，保持对比条件一致。布局形态、信息优先级、导航方式及触控路径分别设计。

## 旋转原则

1. 旋转是重排，不是截取、拉伸或创建另一份应用数据。
2. 应用用稳定 ID 标识。首页与分页容量在同一方案的横竖屏之间保持一致，按线性顺序重新排入列。
3. Dock 保持底部居中，始终与内容留出距离。
4. 文件夹、搜索、应用演示浮层保持打开，输入与编辑焦点不因旋转丢失。
5. 当前页、音乐演示状态、专注计时、工作区与排序保持。
6. 原生实现将使用窗口宽度分级处理分屏与自由窗口；本轮仅覆盖完整平板窗口和浏览器预览缩放。

| 方案 | 横屏 | 竖屏 | 固定状态 |
| --- | --- | --- | --- |
| 浮光 | 6 列图标；每页最多 18 项 | 4 列图标；仍为同一页最多 18 项 | 当前页 / 线性顺序 / 编辑目标 |
| 晨屿 | 左侧 350dp 组件；右侧 4 列应用 | 顶部 2 列组件；下方 4 列应用 | 组件状态 / 分页 / 播放状态 |
| 留白 | 问候与 6 项精选列表并排 | 问候在上，列表在下 | 精选列表 / 计时 |
| 工作台 | 左导航 + 两个并排内容卡片 | 顶标签 + 两个上下内容卡片 | 当前工作区 / 备忘录内容 |
| 星轨 | 左时间栏 + 2×2 分区；分区内 3 列 | 顶部时间与问候 + 2×2 分区；分区内 2 列 | 当前展开的分类 |

## 交互反馈

- 点击按钮：约 180ms 的按压与恢复反馈。
- 打开浮层：背景虚化、约 220ms 淡入与约 280ms 位移缩放。
- 排序：长按约 560ms 后进入编辑；选中目标描边；拖动或使用前后移动按钮，立刻保存线性顺序。
- 页码：当前页用较宽的圆点表示，兼顾可见反馈与点击切换。
- 搜索：按应用中文名称与英文 ID 本地过滤；空结果展示明确反馈。
- 沉浸：优先请求浏览器全屏，不支持时使用 CSS 沉浸；保留可见退出按钮。
- 可访问性：语义按钮、可见焦点、浮层 Tab 循环、Esc 关闭、前后排序替代拖拽、减少动态效果设置。

## 原生实现约束

- 正式启动应用时通过 Android `LauncherApps` / 启动 Activity，H5 不通过 URL scheme 模拟系统权限。
- 用户确认后通过 HOME 角色成为默认桌面，保留回到荣耀桌面的路径。
- 系统边缘返回手势不与 H5 所示的横向分页无条件争抢。
- 真实小组件使用 `AppWidgetHost`，需要额外绑定授权；不把 H5 组件状态当作已完成系统接入。
- 桌面 Dock 与 MagicOS 的系统任务栏可能并存，原生验证阶段需确定遮挡和系统手势行为。
- 系统控制中心、系统任务切换器和系统分屏不属于普通 Launcher 权限。工作台卡片代表内容预览入口。

## 方案选定后

导出 JSON 记录方案 ID、名称、`applicationId`、选择时间与旋转策略。以选中的布局作为 Android MVP 基础，再做真实应用列表、启动与返回 Home、状态持久化、横竖屏、Insets 和性能验证。
