# EasyLauncher

独立的 Android 平板桌面项目，当前处于 **H5 交互设计选型阶段**。

- 产品名：`EasyLauncher`
- Android 包名 / 后续 applicationId：`com.vincenthu.launcher`
- 目标设备：荣耀 `ROD2-W09`，MagicOS 11 / Android 17
- 当前交付：五套可交互 H5 桌面、横竖屏重排、方案比较与选择导出。

当前目录独立于上层 Swift / Xcode 工程，没有 npm 依赖，也不需要构建即可预览。此阶段尚未创建或安装 Android APK；原生 Launcher 在方案确定后开发，包名固定使用上述值。

## 预览

直接用浏览器打开 `prototypes/index.html`，即可离线体验。CSS、JavaScript、图标和壁纸全部在本地，不依赖 CDN、图片服务或外部字体。

也可以启动本地服务：

```bash
cd EasyLauncher
npm run dev
```

没有 npm 时可用：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes
```

浏览器打开 `http://127.0.0.1:8765/`。

在连接的 Android 设备上体验时，可手动执行 `adb reverse tcp:8765 tcp:8765`，然后在设备浏览器打开同一地址。点击右上角全屏按钮进入设备体验，自动跟随视口方向；浏览器不支持 Fullscreen API 时仍会进入页面沉浸模式。USB 预览完成后可执行 `adb reverse --remove tcp:8765`。

## 五个设计方向

| 方案 | 结构 | 特色交互 | 横竖屏适配 |
| --- | --- | --- | --- |
| 01 浮光 | iPad 灵感图标网格 + 玻璃 Dock | 分页、文件夹、长按编辑和拖拽排序 | 横屏 6 列 → 竖屏 4 列，应用顺序不变 |
| 02 晨屿 | 天气 / 日程 / 音乐组件 + 应用网格 | 组件展开、播放状态、搜索 | 左右双区 → 顶部组件 + 下方网格 |
| 03 留白 | 大字问候 + 精选应用列表 | 专注计时、文字入口、全应用搜索 | 左右并排 → 上下阅读 |
| 04 工作台 | 工作区导航 + 内容预览 | 工作 / 创作 / 生活切换、可编辑备忘录 | 左导航 → 顶标签；内容并排 → 堆叠 |
| 05 星轨 | 时间栏 + 四个应用分区 | 分类展开、常用应用直达 | 时间侧栏 → 顶栏；分区内部 3 列 → 2 列 |

## 可操作内容

- 点击顶部方案卡切换设计。
- 点击横屏 / 竖屏，查看重排。自动模式和全屏体验均按当前视口宽高比切换，可跟随设备旋转。
- 点击应用查看打开浮层；备忘录可输入并自动保存到本地浏览器。
- 点击文件夹 / 分区「全部」展开；点击浮层外、关闭按钮或 Home 指示条返回。
- 桌面左右滑动、点击页码或使用方向键翻页。
- 浮光 / 晨屿 / 留白：长按应用约 560ms，或右键进入编辑。支持鼠标拖拽、触屏二次按住移动；也提供点选后「前移 / 后移」按钮，方便跨页排序和触控操作。
- 晨屿：音乐播放 / 暂停仅改变演示状态，不播放音频。
- 留白：25 分钟计时可以开始 / 暂停，切换方案或旋转不重置。
- 工作台：切换三个工作区；内容卡片进入相应应用演示。
- 星轨：每个分区可展开完整分类。
- `/` 打开搜索，`Esc` 关闭浮层或结束编辑，`Tab` 使用浏览器焦点导航。
- 选择方案后，可切换到其他方案继续比较。点击「导出我的选择」下载包含包名、方案 ID 和旋转策略的 JSON。

## 状态与实现边界

默认应用、日期时间、天气、日程与文件均为设计示例，不读取设备隐私数据。控制面板开关仅演示 UI 状态；亮度滑杆只改变预览区域亮度。

旋转时仅修改屏幕尺寸与 CSS 布局，不重建交互 DOM，因此当前分页、编辑目标、搜索内容、打开的文件夹、备忘录输入、音乐与计时状态保持。应用顺序、备忘录、当前方案及选择结果保存在浏览器 `localStorage`；私密模式或禁止存储时退化为内存状态。

Android 原生开发采用独立工程，使用 `com.vincenthu.launcher` 的 `namespace` 和 `applicationId`，通过 HOME 角色实现默认桌面。H5 工作台里的内容卡片是桌面内容预览，不代表能够接管 Android 多任务窗口。系统通知中心、任务切换器、锁屏和系统分屏仍由 MagicOS 提供。

详细设计约束参见 `design/interaction-spec.md`。

## 检查

```bash
npm run check
```

语法检查之外，需在浏览器验证五套方案 × 两个屏幕方向、窄屏选择器、搜索 / 文件夹旋转保留、排序与工作区切换。`qa/` 为本地检查产物目录，不提交生成的逐张截图。
