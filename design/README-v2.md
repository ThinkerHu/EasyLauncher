# EasyLauncher

独立 Android 平板桌面项目。产品名 `EasyLauncher`，包名 / 后续 applicationId：`com.vincenthu.launcher`。

当前交付为 **第二轮 H5 桌面选型**：10 种独立的桌面结构、专属交互、横竖屏重排、候选比较与选择导出。此轮从信息、时间、空间、任务与使用习惯出发设计，不以 iPad 为视觉或交互基准。

## 打开原型

直接打开 `prototypes/index.html` 可离线运行。无 npm 依赖、无 CDN、无外部字体或图片请求。

```bash
cd EasyLauncher
npm run dev
```

浏览器访问 `http://127.0.0.1:8765/`。也可以执行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes`。

旧五套原型完整归档在 `prototypes/archive-v1/index.html`，新页面底部也有入口。第一轮说明与总览在 `design/*-v1.*`。

## 十种方向

| # | 名称 / 类型 | 找到应用的方式 | 可体验交互 | 横竖屏 |
| --- | --- | --- | --- | --- |
| 01 | 刊物 / 杂志桌面 | 栏目与内容 | 切栏目、内容与目录联动 | 跨页 → 头条 + 双栏目录 |
| 02 | 色块 / 磁贴桌面 | 位置、面积与颜色 | 调整模式、磁贴置顶 | 四列 → 两列 |
| 03 | 罗盘 / 环形桌面 | 先选意图，再选应用 | 环形分类、圆心展开完整分类 | 罗盘与结果并排 → 上下 |
| 04 | 时序 / 时间轴桌面 | 从一天的时段进入 | 前后日期、设为当前时段 | 水平 → 垂直时间轴 |
| 05 | 进程 / 任务板桌面 | 从任务启动关联应用 | 新任务、阶段流转 | 三列 → 三组纵排 |
| 06 | 地形 / 空间地图桌面 | 记住应用群的空间位置 | 节点定位、局部应用面板 | 横向路径 → 纵向路径 |
| 07 | 指令 / 命令台桌面 | 输入应用或命令 | 实时检索、Enter 执行、主题切换 | 主区 + 帮助 → 上下排列 |
| 08 | 字序 / 文字索引桌面 | 名称、书签与搜索 | 常用 / 工作 / 创作 / 生活 / 全部索引 | 侧标题 → 顶部标题 |
| 09 | 幕间 / 场景剧场桌面 | 进入工作、创作或休息场景 | 三幕切换、应用组合联动 | 三个拱形舞台 → 纵向场景 |
| 10 | 手札 / 卡片栈桌面 | 逐张浏览主题卡 | 翻卡、收藏与收藏回跳 | 文案与卡片并排 → 上下 |

## 怎么选择

1. 点击顶部 10 张方案卡，右侧提供该方案的专属体验步骤与旋转说明。
2. 横屏 / 竖屏显示 1200×768 / 768×1200 设计空间，按目标荣耀平板 3000×1920 px、400 dpi 的比例制作。
3. 自动方向跟随浏览器视口宽高比。全屏体验隐藏选择器并随设备方向切换；不支持 Fullscreen API 时退化为页面沉浸模式。
4. 可先「加入候选」多个方案，再在下方「我的候选」表格里比较。
5. 「选定此方案」保存最终选择；「导出选择」下载 JSON，包含包名、版本、候选、最终方案及旋转策略。

## 通用交互

- 所有方案都支持「全部应用」搜索与应用打开演示。
- 备忘录可直接输入，自动保存到本地浏览器。
- `/` 打开全局应用库，`Esc` 关闭浮层，`Tab` 支持键盘访问并在浮层内循环。
- 指令桌面支持中文应用名称、英文 ID，以及 `help` / `work` / `all` / `theme` / `clear`。它只操作本地页面，不执行任何系统 Shell。
- 卡片栈支持左右滑动、左右方向键和可见箭头按钮。
- 各方案独立持有状态。切换方案不会丢失本次会话的操作；旋转只改变布局，不重建输入与浮层。
- 「重置演示」仅重置当前方案会话状态，不清除候选、最终选择或备忘录。

## 状态边界

当前方案、候选、最终选择与备忘录保存在 `localStorage`，与第一轮数据使用不同命名空间。存储受限时退化为页面内存。任务、磁贴、分类、命令、场景、卡片等演示状态只在本次页面会话内保留，刷新会复位。

日期、天气、内容和应用均为设计示例。任务板最多 8 件任务，长任务列表与完整文字索引在自己的区域内滚动，桌面导航始终可见。

此阶段尚未生成或安装 Android APK，也没有修改设备默认桌面。Android 原生阶段使用 `com.vincenthu.launcher` 实现 HOME 应用、真实应用列表与启动。时间轴日程、内容预览、应用分组和任务需要进一步确定真实数据来源；系统锁屏、通知中心和系统多任务由 MagicOS 提供。

## 验证

执行 `npm run check` 检查当前与存档 JavaScript 语法。浏览器检查覆盖十套方案×两个方向、各方案专属操作与旋转保留、320 / 390 / 820 / 1920 宽度、全屏进入退出与搜索。检查记录见 `design/validation-v2.md`；`qa/` 中逐张截图为不提交的本地产物。
